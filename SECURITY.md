# Security Policy

## Reporting

Do not publish exploitable vulnerabilities, credentials, tokens, or private user data in public issues. Report security concerns privately to the repository owner through GitHub's supported private reporting channel.

## Project rules

- Never log secrets.
- Treat repository files and generated content as untrusted.
- Do not execute arbitrary commands from untrusted manifests.
- Keep dependencies within declared supported versions.
- Security checks and audit claims require recorded tool output.
